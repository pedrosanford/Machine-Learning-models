# Supervised Learning

This folder contains Jupyter Notebooks covering supervised machine learning algorithms.
Each notebook is written for beginners and includes theory, code with inline comments,
visualizations, and evaluation metrics.

---

## Notebooks

| Notebook | Algorithm | Description |
|---|---|---|
| [linear_regression.ipynb](linear_regression.ipynb) | Linear Regression | Predicting continuous values with a best-fit line. Covers theory, implementation, and evaluation. |

---

## How to Run

1. Make sure you have Python and Jupyter installed (`pip install notebook scikit-learn matplotlib numpy`)
2. Open a terminal in this folder
3. Run `jupyter notebook`
4. Open the desired notebook and run all cells from top to bottom
